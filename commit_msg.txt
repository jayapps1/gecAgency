feat: Implement Mandatory Password Change Gate, Voluntary Profile Change Password, and Independent Responder Flow

Features & Enhancements:
1. Global Mandatory Password Change Gate:
   - Evaluates `mustChangePassword` flag on login and session restoration (`restoreSession()`).
   - Intercepts temporary password accounts and routes directly to `ChangePasswordScreen` (Mandatory mode) before Dashboard access.
   - Restricts back-navigation in Mandatory mode and offers a "Sign Out" action button.

2. Voluntary Password Change & Profile Security:
   - Added "Account Security" card to ProfileScreen with a "Change Password" button.
   - Navigates to `ChangePasswordScreen` (Voluntary mode) with current password, new password, and confirm password fields.

3. Change Password Workspace:
   - Material 3 Glassmorphic screen (`ChangePasswordScreen.kt`) with lock icons, trailing visibility toggles, and transient in-memory state (`ChangePasswordViewModel.kt`).
   - Locally validates matching confirm password before invoking `authRepository.changePassword`.
   - On success, automatically refreshes staff profile to clear `mustChangePassword` flag and routes to role-specific dashboard.

4. Independent Responder Navigation:
   - Confirmed `StaffRole.RESPONDER` routes directly to `ResponderDashboard.kt` with independent access to assigned incidents, notifications, read-only fleet availability, and profile with zero dependency on `CONTROL_ROOM_OPERATOR`.
